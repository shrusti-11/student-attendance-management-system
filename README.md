# 🎓 Student Attendance Management System

A web-based Student Attendance Management System built using Python, Flask, SQLite3, HTML, and CSS.

## ✨ Features

- 🔐 Admin Login and Logout
- 👨‍🎓 Add, Edit and Delete Students
- 📋 View Student List
- 🔎 Search Students
- ✅ Mark Students Present or Absent
- 📅 Attendance History
- 📊 Attendance Reports
- 📆 Date-wise Attendance
- 📅 Date-range Attendance Reports
- ⚠️ Low Attendance Report
- 📈 Overall Attendance Percentage
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- Python
- Flask
- SQLite3
- HTML
- CSS
